# Лабораторная работа №2
## SONiC: статическая маршрутизация, BGP и сохранение конфигурации
## Персональные параметры

| Параметр | Значение |
|---|---|
| Номер ИСУ | 409453 |
| `STUDENT` | `rodionov` |
| `N` | `53` |
| Management-подсеть | `10.101.53.0/24` |
| Подсеть канала h1–h2 | `10.53.1.0/24` |
| Где выполняется работа | Локальная Linux-машина |

### 1. Топология

- r1 — SONiC, AS 65053.
- r2 — SONiC, AS 65153.
- pc1 и pc2 — Linux-хосты.

Соединения:
- pc1 — r1 Ethernet0;
- r1 Ethernet4 — r2 Ethernet4;
- r2 Ethernet0 — pc2.

### 2. Адресация

| Узел | Интерфейс | IP |
|---|---|---|
| pc1 | eth1 | 10.53.1.10/24 |
| r1 | Ethernet0 | 10.53.1.1/24 |
| r1 | Ethernet4 | 10.53.0.0/31 |
| r1 | Loopback0 | 10.53.255.1/32 |
| r2 | Ethernet4 | 10.53.0.1/31 |
| r2 | Ethernet0 | 10.53.2.1/24 |
| r2 | Loopback0 | 10.53.255.2/32 |
| pc2 | eth1 | 10.53.2.10/24 |

### 3. Статическая маршрутизация

На r1 настроен маршрут 10.53.2.0/24 через 10.53.0.1.
На r2 настроен маршрут 10.53.1.0/24 через 10.53.0.0.

Связность проверена с помощью ping и traceroute.

### 4. Обработка маршрутов в SONiC

Проверена передача маршрута по цепочке:
FRR → APPL_DB → orchagent → ASIC_DB → Linux FIB.

Также проверено добавление статического маршрута через CONFIG_DB.

### 5. Динамическая маршрутизация BGP

Настроены eBGP-соседства:
- r1: AS 65053, сосед 10.53.0.1 (AS 65153);
- r2: AS 65153, сосед 10.53.0.0 (AS 65053).

Каждый маршрутизатор анонсирует свою LAN-сеть и Loopback0.
Соседства перешли в состояние Established. Получено по два удалённых префикса.

### 6. Проверка связности

Проверены ping:
- pc1 → 10.53.2.10;
- pc1 → 10.53.255.2.

В обоих случаях получено 4 ответа из 4, потерь пакетов нет.

### 7. Автоматизация

- configs/r1.sh — настройка интерфейсов r1;
- configs/r2.sh — настройка интерфейсов r2;
- configs/r1-frr.conf — конфигурация BGP r1;
- configs/r2-frr.conf — конфигурация BGP r2;
- apply.sh — применение конфигурации;
- destroy-and-test.sh — пересоздание топологии и проверка.

### 8. Вывод

Развернута виртуальная сеть на базе SONiC. Изучены статическая маршрутизация, eBGP и распространение маршрутов через внутренние компоненты SONiC. Проверена работоспособность сети после повторного развёртывания и применения конфигурации.
